# Sazon Dominicano

Sitio web académico para un restaurante de cocina criolla dominicana. La página presenta la identidad del restaurante, una selección de platos y una invitación a visitar el local.

## Abrir el sitio

Abre `index.html` en un navegador. También puedes abrir la carpeta en Visual Studio Code y usar Live Server.

## Estructura

```text
Sazon Dominicano/
├── index.html
├── css/
│   └── styles.css
└── images/
    ├── mangu-tres-golpes.svg
    ├── mofongo-casero.svg
    ├── sabor-de-casa.svg
    └── sancocho-criollo.svg
```

El HTML usa elementos semánticos de HTML5. Los estilos y las ilustraciones se guardan localmente; el diseño incluye adaptación para pantallas pequeñas.
